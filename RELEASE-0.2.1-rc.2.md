# dsh-approve-for-me 0.4.2

## DeepSeek Harness compatibility

Built and tested against DeepSeek Harness `0.2.1-rc.2` (`687f282e8625c6b8d11ff58211a90524be2e4317`). Use the prebuilt release package or this repository’s compiled artifacts with the official plugin installer.

Peer and `engines.dsh` ranges are `>=0.2.1-rc.1 <0.2.2` (same shape as DSHX 0.9.7). Existing public plugin interfaces remain supported within that range.

Validation was performed on cloud Linux. This release does not claim new macOS Desktop App acceptance.
